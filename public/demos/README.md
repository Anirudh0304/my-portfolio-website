These are static browser demos. Each can be opened directly at its `index.html` URL.

To refresh a demo, run its standalone `npm test` and copy its `index.html`, `styles.css`, `assets`, and compiled `dist` into the corresponding folder here. Keep the bundled font license.

Run `node --test public/demos/*/tests/*.test.mjs` with Node 24 from the portfolio root to check the packaged demos.

- [Conversion Discrepancy Triage case study](conversion-discrepancy-triage/docs/case-study.md)
- [Tender Amendment Review case study](/projects/tender-amendment-review) and [captured evidence](tender-amendment-review/data.json). This demo runs directly from its browser module and uses a fixed snapshot of public Find a Tender releases.
