These are static builds of the two standalone portfolio demos. Each demo runs in the browser and can be opened directly at its `index.html` URL.

To refresh a demo, run its standalone `npm test` and copy its `index.html`, `styles.css`, `assets`, and compiled `dist` into the corresponding folder here. Keep the bundled font license.

The published copies include their case studies and reproducible evidence. Run `node --test public/demos/*/tests/*.test.mjs` with Node 24 from the portfolio root to check both copies.
