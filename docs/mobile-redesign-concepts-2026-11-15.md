COMPLETED: the actual decision page returned `tabbed-dossier` (B). It was implemented after the user's explicit "complete it please", documented with their approved merge, and independently checked. The exploration below is historical.

The user rejected the entire mobile appearance: a flat blue textured screen does not communicate the folded paper. A compact header and improved spacing are insufficient. The first local adaptation remains an unapproved draft. No push or deployment is authorized.

The user selected both exploration and a mobile-specific identity (answers 1, 3). Laptop retains its folded-paper identity; shared QA corrections can proceed separately. Mobile may use a different composition and identity. Preserve truthful experience, original portrait/screenshots, readable live content and navigation. No invented employer outcomes.

Mode: Experience. Recruiters and product peers must quickly recognize the person, current role and actual work, then open experience/projects or contact. Success is a memorable, usable phone experience, rather than desktop panels stacked into an article.

Seven grounded structures, ordered by resonance before selection:
1. Pocket fold: one visibly folded vertical sheet, navigation along exposed crease.
2. Work index: finished project evidence is the opening, compact profile follows.
3. Profile to practice: large portrait joins a readable career excerpt, project previews below.
4. Chapter reader: one readable chapter at a time with explicit previous/next and an index.
5. Work reel: bold cropped typography, a large real project preview, and a thumb navigation rail.
6. Tabbed dossier: personal identity occupies an open file, with large section tabs showing the next destination.
7. Folded cover: a sculptural blue flap visibly reveals the introduction and first work link beneath it.

The surface selection dealt 7, 6, 5 (seed:774a6d9f1a483114). These are composition tests, not approved UI. Show three equally complete 390×844 portrait concepts. Keep palette/type family connections to desktop; directions 6 and 5 can translate the material into a mobile-specific visual system as the user authorized. No decorative fake device or poster. Each must contain usable navigation, current role, actual work, contact/resume access and a visible primary action.
